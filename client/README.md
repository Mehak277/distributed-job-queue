# Distributed Job Queue — Frontend

React-based dashboard for the Distributed Job Queue project.

The frontend provides a dashboard for monitoring queued jobs, viewing job status, filtering jobs, inspecting job details, and retrying failed jobs.

## 🚀 Live Dashboard

[Open Live Dashboard](https://distributed-job-queue-nine.vercel.app/)

## ✨ Features

- Job status dashboard
- Recent jobs listing
- Failed jobs view
- Job statistics
- Status and priority filters
- Client-side job search
- Job details drawer
- Manual retry for failed jobs
- Automatic refresh
- Theme preferences

## 🧰 Tech Stack

- React 19
- Vite
- JavaScript
- CSS
- React Router
